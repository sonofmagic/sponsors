# 支持 icebreaker 的开源工作

[English](./README.en.md) | 简体中文

感谢你支持 [icebreaker（@sonofmagic）](https://github.com/sonofmagic) 的开源项目与技术内容。你的支持会用于项目维护、问题修复、文档完善和工程实践分享。

这里提供两种合作方式：面向个人的永久赞助权益，以及面向企业的限时文档侧栏广告。两类权益独立计算。

## 个人赞助

### 赞助档位

| 档位 | 金额 | 永久权益 |
| --- | ---: | --- |
| 普通支持 | 人民币 20 元 | 公开致谢记录 |
| 铜牌赞助 | 人民币 200 元 | 展示 GitHub 头像、用户名和主页链接 |
| 银牌赞助 | 人民币 1,000 元 | 包含铜牌权益，并进入突出显示的赞助者名单 |

个人赞助默认公开展示，且展示权益永久保留。你可以在确认表单中主动选择不公开。自定义金额按同一 GitHub 账号可核对的累计实付金额计算：累计满 20、200 或 1,000 元时，分别匹配普通支持、铜牌或银牌权益；不足 20 元仍会记录感谢，但不进入公开档位。

## 企业赞助与广告

以下为首期试运营价格。企业广告仅展示在桌面端文档页的右侧栏，不包含移动端、首页或其他页面曝光。

| 套餐 | 试运营价格 | 广告权益 |
| --- | ---: | --- |
| 单站月度广告 | 人民币 2,000 元 | 任选 `weapp-tailwindcss` 或 `weapp-vite`，桌面文档右侧栏独占展示 30 个自然日 |
| 双站月度广告 | 人民币 3,000 元 | 两个站点桌面文档右侧栏独占展示 30 个自然日 |
| 双站季度伙伴 | 人民币 8,000 元 | 两个站点桌面文档右侧栏独占展示 90 个自然日 |
| 定制合作 | 单独沟通 | 协商排期、展示方式或专项合作 |

所有企业套餐均包含永久金牌权益。广告到期后，公司名称、Logo 和目标链接仍会保留在金牌合作伙伴名单中。

### 申请与投放流程

1. 提交[中文企业广告申请](https://github.com/sonofmagic/sponsors/issues/new?template=business-sponsorship-zh.yml)，提供套餐、品牌名称、目标链接、广告文案、替代文本和 Logo 素材。
2. 维护者审核广告内容、素材和可用排期，并确认最终上线日期。
3. 双方确认后再付款；请勿在审核前直接通过个人赞助二维码支付广告费用。
4. 素材部署上线后开始计算 30 或 90 个自然日的投放周期。

每个站点同时最多展示一个付费广告。若投放期间站点故障累计超过 24 小时，受影响时长将顺延。套餐不承诺点击量、转化率、首页曝光或移动端曝光。

### 素材与审核政策

- Logo 接受 SVG、透明 PNG 或 WebP，单个文件不超过 1 MB；
- 必须提供品牌名称、目标 URL、替代文本和简短广告文案；
- 中文文案建议不超过 30 个字，英文文案建议不超过 60 个字符；
- 仅接受合法且与开发者、云服务、工程工具或开源生态相关的广告；
- 不接受博彩、灰色产业、侵权、误导性内容或竞品仿冒；
- 维护者保留对内容、素材、链接、排期和最终展示方式的审核决定权。

由于目前缺少官网可靠的公开 PV 数据，以上价格按首期试运营执行。运行 90 天或完成 3 个付费 campaign 后，将结合官网 PV、点击数据、售罄率和企业反馈重新评估价格，已确认的订单不受后续调价影响。

## 隐私与核对

GitHub Issue 是公开的。请勿提交完整交易单号、付款截图、手机号、邮箱或其他敏感信息。个人赞助如需进一步核对，维护者会另行沟通；企业广告请只在排期与素材审核通过后付款。

## 常见问题

### 可以匿名进行个人赞助吗？

可以。在个人赞助确认表单中选择不公开展示即可。你也可以不提交 Issue，但这样可能无法完成核对或累计档位。

### 个人赞助展示会过期吗？

不会。已确认的个人档位权益永久保留，除非赞助者要求移除，或展示内容违反项目政策。

### 企业广告为什么不直接付款？

广告需要先确认内容合规、素材可用和排期无冲突。审核通过后再付款可以避免无可用档期或素材无法上线时产生退款争议。

### 广告到期后还会展示什么？

侧栏广告会按期下线；公司名称、Logo 和链接会继续以金牌合作伙伴身份永久保留在赞助者名单中。
