# 支持 icebreaker 的开源工作

[English](./README.en.md) | 简体中文

感谢你考虑支持 [icebreaker（@sonofmagic）](https://github.com/sonofmagic) 的开源项目与技术内容。你的赞助将用于持续维护开源项目、修复问题、完善文档，以及分享更多工程实践。

## 赞助者权益

在你愿意公开展示的前提下，可以获得：

- 在我维护的部分有影响力的 GitHub 项目中展示你的 GitHub 头像或名称；
- 在 [icebreaker.top](https://icebreaker.top) 及其他相关网站或项目中展示你的 GitHub 信息；
- 对于较大金额或长期赞助，可另行沟通技术咨询与方案设计。

> 头像或名称展示是可选的。技术咨询属于独立服务，请在赞助前先确认范围、时间与交付方式。

## 赞助档位

为了方便核对，赞助确认表单提供以下金额区间和逐级增加的展示权益：

| 档位 | 金额 | 展示权益 |
| --- | ---: | --- |
| 普通支持 | 人民币 1-99 元 | 仅致谢 |
| 铜牌赞助 | 人民币 100-499 元 | 可展示 GitHub 头像和主页链接 |
| 银牌赞助 | 人民币 500-1,999 元 | 包含铜牌权益，并加入赞助者名单 |
| 金牌赞助 | 人民币 2,000-4,999 元 | 包含银牌权益，并提供首页或显著位置展示及公开致谢 |
| 特别赞助 | 人民币 5,000 元及以上 | 包含金牌权益，可协商定制展示和专项合作 |
| 不便透露金额 | 不公开金额 | 按普通支持处理 |

赞助档位决定可申请的展示权益；公开展示仍需在表单中主动选择，不公开不会影响赞助核对。首页、显著位置、公开致谢和特别赞助合作的具体位置与范围需由维护者确认。

GitHub Issue Form 不支持根据下拉选项动态隐藏或改写字段；表单会在档位选项中直接说明对应权益，提交后按所选档位核对。

## 赞助完成后

请提交一条 [中文赞助确认 Issue](https://github.com/sonofmagic/sponsors/issues/new?template=sponsorship-zh.yml)，以便核对赞助并记录你的展示偏好。新建 Issue 时也可以选择 English sponsorship verification，进入全英文表单。

除赞助档位外，表单中的其他字段都是可选的。未填写支付时间时，以 Issue 创建时间作为参考；未选择展示偏好时，默认不公开展示。愿意提供更多信息时，可以填写：

- GitHub 用户名（可选，Issue 作者通常已经可以识别）；
- 支付方式；
- 赞助档位（必填，具体金额可选）；
- 赞助日期和大致时间；
- 希望公开展示的名称、头像或链接；
- 是否希望匿名。

### 隐私提醒

Issue 是公开的。请勿提交完整交易单号、付款截图、手机号、邮箱或其他敏感信息。如需进一步核对，维护者会与你另行沟通。

## 常见问题

### 可以匿名赞助吗？

可以。展示偏好留空或选择不公开即可；你也可以不提交 Issue，但这样可能无法完成核对。

### 可以只展示名称，不展示头像或链接吗？

可以。请在赞助确认 Issue 中写明你的展示偏好。

### 商业合作或技术咨询如何联系？

请先通过 [GitHub Issue](https://github.com/sonofmagic/sponsors/issues/new) 说明需求，不要直接以赞助代替服务费用。双方确认范围后再继续。
